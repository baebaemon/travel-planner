# 12월 여행 관리

한 달짜리 여행의 일정·예약·준비물·예산·중요 정보를 한 화면에서 보는 정적 웹페이지.
설치나 서버가 필요 없다. `index.html` 을 브라우저로 열면 된다.

## 사용법

1. `travel/index.html` 을 더블클릭해서 연다 (또는 정적 호스팅에 `travel/` 폴더를 올린다).
2. 처음에는 샘플 데이터가 들어 있다. 상단 배너의 **샘플 지우기** 로 비운 뒤 직접 입력한다.
3. **여행 정보** 에서 여행 이름, 여행지, 출발일·귀국일, 예산을 정한다. 기본값은 2026-12-01 ~ 12-31.

| 탭 | 내용 |
|---|---|
| 대시보드 | D-day, 오늘 일정, 다가오는 예약, 미결제 예약, 남은 준비물, 예산 사용 현황 |
| 일정 | 날짜별 일정. 예약(항공·숙소 등)도 해당 날짜에 함께 표시 |
| 예약 | 종류별 예약 카드. 예약번호, 금액, 결제 여부 토글, 예약 페이지 링크 |
| 준비물·할일 | 분류별 체크리스트와 진행률 |
| 예산 | 지출 내역, 분류별 합계, 예산 대비 사용률, 예약 총액 |
| 중요 정보 | 여권 만료일, 보험, 긴급 연락처, 대사관 등 자유 항목 |

## 데이터 저장

- 입력한 내용은 **이 브라우저의 localStorage** 에 저장된다. 서버로 전송되지 않는다.
- 다른 기기나 브라우저로 옮기려면 **내보내기** 로 JSON 을 받고, 그 기기에서 **가져오기** 를 한다.
- 브라우저 데이터를 지우면 내용이 사라지므로, 중요한 정보는 주기적으로 내보내기를 해 두는 것을 권한다.

## 파일

- `index.html` — 화면 골격과 대화상자
- `styles.css` — 스타일 (밝은 테마 / 다크모드 자동 적용)
- `app.js` — 데이터 저장, 렌더링, 추가·수정·삭제 로직

## 확장 아이디어

- 환율·시차 표시, 날씨 위젯
- 예약 확인 메일 붙여넣기 → 자동 항목 생성
- 여러 명이 함께 쓰는 경우 공유 저장소(예: Google Sheets, Supabase) 연결
